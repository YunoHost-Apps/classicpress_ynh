### The CMS for Creators
A lightweight, stable, familiar content management system. Forked from WordPress without the block editor (Gutenberg). ClassicPress core is half the size of WordPress.

- HTML5 Throughout
- Choice of Upload Folders
- Obsolete JavaScript Libraries Removed
- Updated Audio and Video Player
- Object Relationships Database Table
- New Media Library Grid
- See Where Media are Used
- Media Categories and Tags
- Revisions Management
- Bulk and Quick Edit Media
- Accessible Menus and Modals
- User Groups
